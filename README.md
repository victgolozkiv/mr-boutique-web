# 💎 Mr. Boutique — Sitio Web de Joyería

> **Este sitio web fue creado para mi primo Chuy y su negocio de joyería.**

## ✨ Sobre el Proyecto

**Mr. Boutique** es una tienda en línea de joyería premium, especializada en:

- 🥇 Oro Laminado 18k
- 💎 Zirconias de alta calidad

Con envíos a todo México desde **Jiménez, Chihuahua**.

## 🛍️ Funcionalidades

- Catálogo de productos con galería de imágenes y videos
- Filtros por categoría (Oro Laminado / Zirconias)
- Modal de detalle de producto con selector de variantes
- Carrito de compras con cupones de descuento
- Botón de compra directa por **WhatsApp**
- Sección de reseñas y preguntas frecuentes
- Diseño responsivo y elegante (dark mode con dorado)

## 🗂️ Estructura

```
├── index.html      # Página principal
├── style.css       # Estilos y diseño
├── script.js       # Lógica del carrito y catálogo
└── assets/         # Imágenes y videos de productos
```

## 🚀 Uso

Abre `index.html` en cualquier navegador. No requiere servidor ni instalación.
